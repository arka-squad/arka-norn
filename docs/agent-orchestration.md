# Agent Orchestration

Product control derives a bounded role from the next Pipeline action, verifies the Agent registry and creates reusable prompts. Essential and FastDev route audit, development and QA through their guided skill; Complete uses a specialized phase skill.

Automatic orchestration remains assisted:

1. prepare a mission preview
2. select an explicitly configured provider and model
3. confirm the immutable fingerprint
4. launch a disposable local worker
5. accept success only with an execution-bound proof and a new valid signed document
6. require a fresh preview before another mission

Read-only audit missions cannot advance the Pipeline on provider prose alone. They return a closed analysis verdict and require human validation of the official document.
