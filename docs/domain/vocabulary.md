# Domain Vocabulary

- Project: product repository boundary and Agent registry owner.
- Feature: scoped delivery unit belonging to one Project.
- Pipeline: ordered workflow definition and business policies.
- Document: signed JSON evidence for one canonical step.
- Run: implementation or review execution represented by documents and execution records.
- Agent: explicit provider/role identity with scope and lineage.
- Session: isolated current-Agent selection.
- Handoff: transversal signed transfer between Agents.
- Content locale: language of human prose inside a v5 document.
- Display locale: language used by CLI, TUI and Agent responses.
