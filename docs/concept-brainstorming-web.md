# Concept Brainstorming Prompt

Use an external conversational interface only to explore options. Do not treat its prose as a signed Feature document.

Provide the verified Project and Feature context, problem, users, constraints, known evidence and open questions. Ask for alternatives, risks and testable assumptions. Bring selected decisions back into the canonical `concept` or `feature_brief` scaffold, set `content_locale`, sign it with the active Agent and validate it locally.
