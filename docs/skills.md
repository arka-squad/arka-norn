# Skills

The `all` profile installs exactly 21 generated skills. Definitions are compiled from one English configuration by `scripts/generate-v2-skills.mjs`; checksums in the v2 catalog cover normalized source bytes.

Canonical guided skills are `arka-essential` and `arka-fastdev`. They execute one calculated action, preserve the specialized session, validate the signed artifact and stop. Complete workflow roles use canonical English skill IDs.

Skills accept English and French triggers, consult the active locale, answer in that language and always use English document contracts with `content_locale`.
